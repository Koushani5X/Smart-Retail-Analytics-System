Smart Retail Analytics System Using Machine Learning & Market Basket Analysis

📌 Project Overview

The Smart Retail Analytics System is a Python-based Machine Learning project designed to analyze retail sales data and understand customer purchasing behavior. It combines data analytics, predictive modeling, customer segmentation, and market basket analysis to generate meaningful business insights.

🎯 Project Objectives

- Analyze retail sales transactions and purchasing patterns.
- Segment customers based on their spending behavior.
- Predict sales amounts using Machine Learning.
- Identify frequently purchased product categories.
- Discover purchasing patterns using Market Basket Analysis.
- Recommend popular product categories based on transaction frequency.

📂 Dataset Description

The project uses a Retail Sales Dataset containing 1,000 transactions with the following attributes:

- Transaction ID and Date
- Customer ID, Gender, and Age
- Product Category
- Quantity and Price per Unit
- Total Amount

🤖 Machine Learning & Analytical Techniques

1. Customer Segmentation – K-Means Clustering

Groups customers into three segments: Low Value, Medium Value, and High Value based on their purchasing behavior and spending patterns.

2. Sales Prediction – Linear Regression

Builds a regression model to predict sales amounts using transaction-related features.

3. Market Basket Analysis – Apriori Algorithm

Identifies frequent itemsets and association patterns among product categories to understand customer purchasing preferences.

4. Product Recommendation

Identifies popular product categories based on transaction frequency to provide insights into customer preferences.

5. Data Analysis & Visualization

Uses statistical analysis and visualizations to explore sales trends, customer behavior, and product performance.
